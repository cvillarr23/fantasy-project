Component library

The web UI's Storybook component library is built from fantasy-web-ui at site build time. This build didn't include it.

To see it locally, run npm ci && npm run build-storybook in a fantasy-web-ui checkout beside this site, or set FANTASY_DOCS_ROOT to the directory containing your source checkouts, then run npm run build again. CI builds it from the repository's default branch.
