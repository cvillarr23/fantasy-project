# fantasy-project
Cross-cutting planning/epics for the fantasy-* project — home of the wayfinder map and the project docs site.

The docs site is [Docusaurus](https://docusaurus.io/), built from `docs/`:

```bash
npm ci
npm start        # dev server
npm run build    # production build; fails on broken links
```

See `docs/contributing/docs-style-guide.md` before adding pages.
